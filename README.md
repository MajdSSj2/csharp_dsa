# Data Structures & Algorithms in C#

A collection of **Data Structures, Algorithms, and problem-solving exercises implemented in C# and .NET**.

This repository documents my journey learning Data Structures and Algorithms by implementing them from scratch, solving problems, and understanding **why the algorithms work** rather than simply memorizing solutions.

The main goals of this repository are to improve my understanding of:

- Data structures and their internal behavior
- Algorithms and problem-solving
- Time and space complexity
- References and object relationships
- Recursion and iterative solutions
- Choosing the appropriate data structure for a problem
- Writing clean and readable C# code

# Learning Approach

For each topic, I try to follow this process:

```text
Learn the concept
      ↓
Understand the internal behavior
      ↓
Implement it manually
      ↓
Trace the code step by step
      ↓
Test edge cases
      ↓
Analyze time and space complexity
      ↓
Solve problems using it
```

The focus is on understanding rather than memorization.

# Running the Projects

Make sure the .NET SDK is installed.

Check your version:

```bash
dotnet --version
```

Clone the repository:

```bash
git clone https://github.com/MajdSSj2/csharp_dsa
```

Enter the repository:

```bash
cd csharp-dsa
```




Then run it:

```bash
dotnet run
```
